# 💕 爱的时光机 (Love Web)

一个表达爱意的爱情主题 Web 网站，基于 Node.js + Express。

## ✨ 功能

- 🏠 **首页**：在一起天数计算、爱情故事时间线（增删排序）、每日情话、爱心背景
- 📷 **甜蜜动态**：发布文字动态 + 固定封面选择
- 🛒 **爱心点单**：5 大分类菜单 + 自定义点单 + 备注功能 + 订单通知
- 💌 **写给你的信**：打字机效果情书、爱心雨动画、情话生成器、节日倒计时
- 🔔 **点单通知**：新订单在首页弹窗提醒

## 🚀 本地启动

\\\ash
npm install
npm start
\\\

然后打开 http://localhost:3000

## ☁️ 部署到 Render

详见 [render.yaml](./render.yaml)，Render 一键部署配置已准备好。

步骤：
1. 登录 https://dashboard.render.com
2. New → Web Service → 连接本仓库
3. Build Command: \
pm install\
4. Start Command: \
pm start\
5. Environment: Node 18
